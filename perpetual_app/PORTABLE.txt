PERPETUAL · FLIGHT CONSOLE · EARLY TEST BUILD

This is an early test build for the Perpetual flight computer, not a stable release.

START
Extract the whole folder and run Perpetual.exe. Keep the _internal folder next to it.
Python is not needed on the target PC. The build is not signed, so Windows SmartScreen
may warn on first launch (More info -> Run anyway).

GUIDE
Step-by-step guide with screenshots, from setting up the board to reading a flight:
https://github.com/rotellini9809/perpetual_code/blob/main/docs/APP_GUIDE.md

LANGUAGE
The app starts in English. Choose Italian in Settings -> Language; it applies after a restart.
Error messages stay in English.

CONNECTION
At startup the app tries once to connect: USB first, then a paired outgoing Bluetooth SPP port.
Use Connect to retry, or Manual port to pick a specific port.
Close Serial Monitor and any other app that uses the same port.
The link is confirmed by the board's replies, not by the Windows Bluetooth settings.

PAGES
Dashboard: applied rules, sensors, preflight checks, pyro continuity, servo preparation and
  ARM / DISARM (hold for 1.5 s). The board decides whether arming is allowed.
Configuration: deployment rules, channels and IMU calibration. Changes stay in a local draft
  until Validate and Apply; Discard drops them.
Test and simulation: onboard simulation (Hoppino, or a 25 s two-boost profile in bistage mode),
  with optional recording to memory and optional physical outputs.
Recorded flights: read the flight list, download CSV + JSON, view the plots, or open a local CSV.
Settings: board orientation, state machine, airbrakes, language, factory reset and memory format.
Console: manual commands and the board's replies.

GOOD TO KNOW
Nothing is saved to the board automatically: Apply and each Save button are explicit.
Downloading over existing files asks for confirmation. The files are replaced only when the
download completes; a cancelled or failed download leaves them unchanged.
Closing the app with unapplied local changes asks for confirmation; they are lost if you close.
Numbers always use a decimal point.
